# TrueForge Local Skills (dz-*)

Curated, high-performance skills specifically tailored for TrueForge agents to interact with local MCP microservices:

- **dz-searxng-search-web-search**: Privacy-preserving web search across Google, Bing, DuckDuckGo, arXiv via SearXNG.
- **dz-crawl4ai-scraper-web-scraper**: Headless web page extraction, Javascript rendering, and clean LLM Markdown generation via Crawl4AI.
- **dz-doc-diagram-renderer-mermaid-diagrams**: Architecture diagrams, flowcharts, entity-relationship diagrams, and sequence diagrams exported as SVG/PNG.
- **dz-doc-diagram-renderer-typst-pdf-reports**: Publication-quality executive summaries, whitepapers, invoices, and analytical reports compiled to PDF via Typst.
- **dz-doc-diagram-renderer-marp-presentation-deck**: Beautiful pitch decks and slide presentations compiled to standalone HTML or PDF via Marp.
- **dz-duckdb-analytics-sql-analytics**: Fast SQL analytics over CSV, JSON, Parquet, and multi-tab Excel spreadsheet generator via DuckDB.
