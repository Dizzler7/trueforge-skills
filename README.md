# TrueForge Local Skills

Curated, high-performance skills specifically tailored for TrueForge agents to interact with local MCP microservices:

- **searxng-web-search**: Privacy-preserving web search across Google, Bing, DuckDuckGo, arXiv via SearXNG.
- **crawl4ai-web-scraper**: Headless web page extraction, Javascript rendering, and clean LLM Markdown generation.
- **mermaid-diagrams**: Architecture diagrams, flowcharts, entity-relationship diagrams, and sequence diagrams exported as SVG/PNG.
- **typst-pdf-reports**: Publication-quality executive summaries, whitepapers, invoices, and analytical reports compiled to PDF.
- **marp-presentation-deck**: Beautiful pitch decks and slide presentations compiled to standalone HTML or PDF.
- **duckdb-sql-analytics**: Fast SQL analytics over CSV, JSON, Parquet, and multi-tab Excel spreadsheet generator.
